==================== PASOS DE LA PRACTICA (texto del PDF) ====================

1. En res/values/themes.xml quitar la palabra que esta despues de DayNight
   (.NoActionBar), para que se vea la barra donde sale el menu.
2. Click derecho en res -> New -> Android Resource File.
   File name: menusito   Resource type: Menu   -> OK
   (se crea la carpeta res/menu con menusito.xml)
3. Buscar en internet imagenes de suma, resta, multiplicacion y division en .png
   y pegarlas en la carpeta drawable como: sumar.png, restar.png,
   multiplicar.png, dividir.png
4. Teclear el codigo de menusito.xml (abajo).
5. En MainActivity: click derecho -> Generate -> Override Methods...
   -> Collapse all -> expandir android.app.Activity -> seleccionar
   onCreateOptionsMenu(Menu):boolean y onOptionsItemSelected(MenuItem):boolean -> OK
6. Capturar el codigo de MainActivity (abajo).
7. Al dar click en el icono de suma o en "Suma" del menu de 3 puntitos sale el
   mensaje "fue en suma" abajo (Toast).
8. EJERCICIO: Complementa el ejercicio poniendo dos cuadros de texto y su
   correspondiente clase y sus metodos de suma, resta, multiplicacion y
   division; al seleccionar cualquier icono o cualquier opcion del menu
   despliega el resultado correspondiente.
   (Esto es lo que esta resuelto en 02_OperaFragmentitos.)


==================== JAVA - MainActivity (pantalla principal) ====================
( Java/MainActivity.java )
NOTA: en la captura los imports estan colapsados ("import ..." lineas 3-13);
      estos son los que corresponden a lo que usa el codigo + los de la plantilla.

package com.example.myamenupuntitosnuevo;

import android.os.Bundle;
import android.view.Menu;
import android.view.MenuItem;
import android.widget.Toast;

import androidx.activity.EdgeToEdge;
import androidx.annotation.NonNull;
import androidx.appcompat.app.AppCompatActivity;
import androidx.core.graphics.Insets;
import androidx.core.view.ViewCompat;
import androidx.core.view.WindowInsetsCompat;

public class MainActivity extends AppCompatActivity {

    @Override
    public boolean onCreateOptionsMenu(Menu menu) {
        getMenuInflater().inflate(R.menu.menusito,menu);
        return super.onCreateOptionsMenu(menu);
    }

    @Override
    public boolean onOptionsItemSelected(@NonNull MenuItem item) {
        if(item.getItemId()== R.id.sumita || item.getItemId()== R.id.Sumita )
            Toast.makeText(this,"fue en suma"
                    ,Toast.LENGTH_LONG).show();
        return super.onOptionsItemSelected(item);
    }

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_main);

    }
}

(Detalles tal cual la captura: el if NO lleva llaves; el ",Toast.LENGTH_LONG"
 va en la linea de abajo empezando con la coma; los dos metodos del menu van
 ARRIBA de onCreate porque los genero Override Methods; el bloque
 ViewCompat.setOnApplyWindowInsetsListener de la plantilla esta borrado.)


==================== XML - Menu de opciones ====================
( XML/menu/menusito.xml )

<?xml version="1.0" encoding="utf-8"?>
<menu xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto">
    <item
        android:id="@+id/sumita"
        android:title="suma"
        android:icon="@drawable/sumar"
        app:showAsAction="always" />
    <item
        android:id="@+id/restita"
        android:title="resta"
        android:icon="@drawable/restar"
        app:showAsAction="always"/>
    <item
        android:id="@+id/multiplicadita"
        android:title="multiplicacion"
        android:icon="@drawable/multiplicar"
        app:showAsAction="always"/>
    <item
        android:id="@+id/partidita"

        android:id="@+id/Restita"
